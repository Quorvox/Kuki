# Kuki

Голосовой и текстовый чат для игр. Свои серверы, каналы как в TeamSpeak, демонстрация экрана, картинки в чате.

**Сайт:** https://kuki.quorvox.ru (вход через Quorvox ID)

## Скачать для Windows

Последняя версия лежит в разделе [Releases](../../releases/latest):

| Файл | Для чего |
|---|---|
| `Kuki-Setup-*.exe` | Установщик (рекомендуем): ярлык и удаление как у обычной программы |
| `Kuki-Portable-*.exe` | Один файл, устанавливать не нужно |
| `Kuki-Windows-x64.zip` | Архив: распаковать и запустить `Kuki.exe` |

Файлы пока не подписаны цифровой подписью, поэтому Windows может показать предупреждение SmartScreen.
Нажми «Подробнее», затем «Выполнить в любом случае».

## Зачем приложение, если есть сайт

Сайт позволяет заходить на чужие серверы. Приложение нужно, чтобы **создать свой сервер**: он работает на твоём компьютере
(чат и история хранятся у тебя), а голос и экран идут напрямую между участниками.

Исходный код в этом репозитории не публикуется, здесь только релизы.
